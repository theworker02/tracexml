# tracexml

Trace encode/decode helpers for xml payloads in pipelines.

**Site:** https://theworker02.github.io/tracexml/

## Install / run

```bash
git clone https://github.com/theworker02/tracexml.git
cd tracexml
node src/cli.js
node --test
```
